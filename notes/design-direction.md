# Portfolio design direction

The existing application is Next.js with React, TypeScript, Tailwind, and a JSON-backed content editor. Preserve that architecture and content editor. Angular-specific template and signal rules cannot be applied to React; use server components, typed props, external CSS, and small client components instead.

Use a warm paper background, deep ink text, olive accents, large typography, thin rules, and project imagery. Prioritize work, experience, background, and contact. Content should be readable before JavaScript loads. Avoid entry loaders, mouse-following effects, fake metrics, and decorative terminals.

Use verified CV facts and public repository evidence. Project visuals must be authentic captures or clearly labeled illustrations. Keep links and résumé downloads accessible. Respect reduced motion and support keyboard, narrow viewports, and text zoom.

Measure the production build with Lighthouse and browser checks. Scores describe the tested environment; production hosting and network conditions can change them.
